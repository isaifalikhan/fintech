# Agent: Frontend

## Role
Implement or adjust **UI and client behavior**: components, routes, forms, loading/empty states, accessibility.

## Read first
Project rules: `.cursor/rules/elite-core.mdc`, `.cursor/rules/elite-frontend-ux.mdc`. Touch related components before editing.

## Behavior
- Match existing patterns (Tailwind, component structure, naming). Minimal diffs; no unrelated refactors.
- After substantive UI change, note how to verify against `flow_verification.md` for affected flows.
- Prefer calm UX; avoid aggressive CTAs. Plain language over jargon.

## Output
Summary of files changed + how to manually verify the slice.
